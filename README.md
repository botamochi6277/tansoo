# Tansoo/タンスー

_Tansoo_ is a simple client-side application to organize clothes.

This application is developed with vue, react.js, mui, and sqlite.

A user can

1. register cloth items
1. sort the items
1. analyze stats

cloth item properties:

- name
- purchased date
- brand (e.g. Uniqlo, GU, muji)
- type (e.g. long sleeve t-shirt, long pants, coat)
- color
- cost (yen)
